# 5차 설계: 캐릭터를 컨셉 시트에 맞추기 (v0.5.0)

사용자가 준 캐릭터 컨셉 시트 2장(`docs/design/concept/`)에 게임 캐릭터를 최대한 일치시키고 품질을 올리는 작업입니다. 그림을 그대로 쓰는 것이 아니라(외부 파일 없음, 오프라인), 게임 안에서 코드로 만드는 모델을 그림에 맞춰 다시 만들었습니다.

## 1. 목표와 제약

| 항목 | 결정 |
| --- | --- |
| 기준 그림 | `sheet-1-cast.jpg`(출연진 전체), `sheet-2-imp.jpg`(뿔이 상세). 캐릭터별로 잘라 `crops/`에 둠 |
| 만드는 방식 | 그대로 `CharGeo` 도형으로 조립(정점 색 + 외곽선). 외부 모델·텍스처 파일 없음 |
| 지켜야 할 것 | 리그 규약(뼈 이름, 기준점 = 발 사이 지면, 정면 −Z, 오른손 +X 무기, 왼손 방패), 캐릭터 검사 `tests/character_checks.gd`, 결정적 자세, 저장·규칙 무변경 |
| 예산 | 삼각형 캐릭터 4,000 / 보스 6,000 / 뿔이 6,000(이전 3,000 / 4,500). 컨셉 시트의 "로우폴리 기준 2,000~5,000"에 맞춤. 검사가 config 를 읽음 |
| 비율 | 시트의 공통 비율: 거대형 3.5등신(보스), 일반형 3등신(기사·고블린·오크), 소형 2.5등신(뿔이·해골). 키 검사 기준은 유지(고블린 1.0, 기사 1.15, 보스 1.3) |

## 2. 기반(모든 캐릭터 공통)

- **파일 분리:** `character_rig.gd`(리그·자세·표정)와 `char_geo.gd`(도형·공통 부품), `scripts/world/chars/*_builder.gd`(캐릭터별 외형). 캐릭터마다 다른 사람이 동시에 작업할 수 있게 나눴습니다.
- **새 도형:** 초타원체 `rounded_box`(모서리가 둥근 상자), `spline_tube`(마디마다 반지름이 다른 매끈한 관: 뿔·꼬리·몽둥이·창·머리카락), `horn`, `torus`(털 테두리·왕관 띠), `polygon`/`star`(문장·왕관 톱니·방패 모양), `wing`(양면 박쥐 날개), `cape`(양면 천).
- **눈 옵션:** 공막 색(용의 노란 눈), 세로 동공, 눈 테두리, 눈 가로 폭, 반사광 크기, 눈썹 길이·두께.
- **재질:** 캐릭터 전용 `CharacterRig.character_material()` — 감싸는 확산광(그늘이 부드럽게), 약한 반사광, 가장자리 림 라이트. 그림의 매끈한 장난감 질감에 가깝게. 건물 재질은 그대로.
- **캡처:** `tests/character_capture.gd --mode=solo --who=…`(정면·3/4·옆·뒤·동작·표정·게임 크기), `--mode=cast`(전체 출연진), `--mode=geo`(도형 견본). `tools/montage.py`로 한 장에 모아 봄.

## 4. 검증 방법

1. 캐릭터 검사(관절·발 높이·키·무기 손·충격 위상·표정·예산)와 규칙 검사(뿔이 설계 검사 포함) 통과.
2. 작업자와 다른 심사자가 캡처와 컨셉 그림을 비교해 일치도·품질을 10점 만점으로 매기고, 기준(일치 7.5, 품질 7, 막힘 없음) 미달이면 보완 라운드.
3. 통합 뒤 게임 시점 캡처(마을·전투·이야기 창)로 멀리서도 읽히는지, 성능(그리기 호출·삼각형)이 상한 안인지 확인.
