# 5차 설계: 캐릭터를 컨셉 시트에 맞추기 (v0.5.0)

사용자가 준 캐릭터 컨셉 시트 2장(`docs/design/concept/`)에 게임 캐릭터를 최대한 일치시키고 품질을 올리는 작업입니다. 그림을 그대로 쓰는 것이 아니라(외부 파일 없음, 오프라인), 게임 안에서 코드로 만드는 모델을 그림에 맞춰 다시 만들었습니다.

## 1. 목표와 제약

| 항목 | 결정 |
| --- | --- |
| 기준 그림 | `sheet-1-cast.jpg`(출연진 전체), `sheet-2-imp.jpg`(뿔이 상세). 캐릭터별로 잘라 `crops/`에 둠 |
| 만드는 방식 | 그대로 `CharGeo` 도형으로 조립(정점 색 + 외곽선). 외부 모델·텍스처 파일 없음 |
| 지켜야 할 것 | 리그 규약(뼈 이름, 기준점 = 발 사이 지면, 정면 −Z, 오른손 +X 무기, 왼손 방패), 캐릭터 검사 `tests/character_checks.gd`, 결정적 자세, 저장·규칙 무변경 |
| 예산 | 삼각형 캐릭터 4,000 / 보스 6,000 / 뿔이 6,000(이전 3,000 / 4,500). 컨셉 시트의 "로우폴리 기준 2,000~5,000"에 맞춤. 검사가 config 를 읽음 |
| 비율 | 시트의 공통 비율: 거대형 3.5등신(보스), 일반형 3등신(기사·고블린·오크), 소형 2.5등신(뿔이·해골). 키 검사 기준은 유지(고블린 1.0, 기사 1.15, 보스 1.3) |

## 2. 기반(모든 캐릭터 공통)

- **파일 분리:** `character_rig.gd`(리그·자세·표정)와 `char_geo.gd`(도형·공통 부품), `scripts/world/chars/*_builder.gd`(캐릭터별 외형). 캐릭터마다 다른 사람이 동시에 작업할 수 있게 나눴습니다.
- **새 도형:** 초타원체 `rounded_box`(모서리가 둥근 상자), `spline_tube`(마디마다 반지름이 다른 매끈한 관: 뿔·꼬리·몽둥이·창·머리카락), `horn`, `torus`(털 테두리·왕관 띠), `polygon`/`star`(문장·왕관 톱니·방패 모양), `wing`(양면 박쥐 날개), `cape`(양면 천).
- **눈 옵션:** 공막 색(용의 노란 눈), 세로 동공, 눈 테두리, 눈 가로 폭, 반사광 크기, 눈썹 길이·두께.
- **재질:** 캐릭터 전용 `CharacterRig.character_material()` — 감싸는 확산광(그늘이 부드럽게), 약한 반사광, 가장자리 림 라이트. 그림의 매끈한 장난감 질감에 가깝게. 건물 재질은 그대로.
- **캡처:** `tests/character_capture.gd --mode=solo --who=…`(정면·3/4·옆·뒤·동작·표정·게임 크기), `--mode=cast`(전체 출연진), `--mode=geo`(도형 견본). `tools/montage.py`로 한 장에 모아 봄.

## 3. 캐릭터별 결정

캐릭터마다 작업자(에이전트)가 자기 작업 사본에서 모델을 만들고, 다른 심사자가 캡처와 컨셉 그림을 비교해 일치도·품질을 10점 만점으로 매겼습니다. 기준(일치 7.5·품질 7·막힘 없음)에 못 미치면 보완 라운드를 돌렸고, 마지막에는 제작자가 그림을 보고 고칠 목록을 직접 써 준 보완 라운드를 한 번 더 했습니다. 아래 점수는 마지막 심사입니다. 캡처는 `docs/design/v5/<이름>/review.jpg`(정면·3/4·옆·동작·게임 크기·표정)에 있습니다.

### 뿔이(주인공) — 일치 7.5 / 품질 7, 삼각형 Lv.1~4 5,189 / 5,305 / 5,881 / 5,989

- 컨셉 2번 시트의 "작지만 위대한 마룡왕": 흑자색 용 몸(배는 밝은 자색 비늘판), 좌우 대칭의 큰 회색 뿔(옆·뒤로 쓸었다가 위로), 금 왕관과 붉은 보석(두개골 가운데, 앞 톱니가 가장 높음), 노란 공막에 세로 동공·짙은 눈 테두리의 아몬드 눈, 송곳니, 박쥐 날개(어깨뼈에서 위로 펼침, 막 가운데 밝은 띠), 가시 꼬리, 발톱 셋 손발, 금 허리띠·왕관 문장 앞치마·가슴 보석.
- 성장: Lv.1 작은 왕자(작은 뿔·3톱니 왕관·작은 날개·작은 허리띠) → Lv.2 뿔·날개 커짐, 어깨 징 → Lv.3 붉은 털 망토·금 어깨 장식 → Lv.4 높은 5톱니 왕관·큰 망토(꼬리 구멍 둘레 털 고리)·금 가슴판. 네 레벨은 다른 메시(규칙 검사 `test_imp_design`이 뿔 대칭·자람, 왕관, 망토 뼈, 예산을 확인).
- 지팡이는 뺐습니다(컨셉에 없음). `def.tip`은 오른손 발톱. 걷기·무서운 척·환호 자세는 두 손 기준으로 다시 썼습니다.
- 남은 차이: 순수 옆 모습에서는 대칭 뿔이 하나로 겹쳐 보임(직교 캡처 특성), Lv.2에 짧은 망토·털 깃을 더 주면 성장 단계가 더 또렷해짐(심사 의견), 꼬리 구멍 털 고리가 뒤에서 조금 큼.

### 고블린 일꾼 3종 — 일치 7 / 품질 8, 삼각형 3,534 / 3,758 / 3,572(투구, 망치 없이 3,354)

- 0 일반: 이마에 올린 놋쇠 고글(하늘색 렌즈), 보라 조끼(열린 V넥)·갈색 바지·벨트 주머니, 작은 망치. 1 건설형: 큰 돌망치(게임 자세상 어깨에 메지 않고 손에 듦), 가슴끈. 2 방어탑 조작수: 갈색 쇠 투구와 두 뿔(방어탑 위 조작수는 이 변형, `Models.defense_tower`).
- 공통: 밝은 초록 피부, 큰 잎 귀(2차 움직임 뼈), 큰 코, 아래 송곳니 둘, 이마에 박힌 짙은 눈썹, 흰자·큰 눈동자·반사광, 2.8등신.
- 남은 차이: 고글 렌즈가 컨셉보다 작음, 귀가 넓고 수평에 가까움(심사 의견).

### 꼬마 오크·해골 궁수 — 일치 8 / 품질 7, 삼각형 3,907 / 3,582

- 오크: 올리브 피부, 탱크 몸통(어깨 폭 ≈ 머리 1.4배)·둥근 어깨 받이·왕주먹, 두툼한 쐐기 모히칸, 위로 솟은 엄니, 짙은 가죽 조끼·벨트, 길고 굵은 징 박힌 몽둥이. 옛 모델이 쓰러질 때 손이 땅 아래로 내려가던 검사 실패를 새 모델이 통과.
- 해골 궁수: 두개골(파인 눈두덩 능선·둥근 눈구멍·붉은 빛점·이빨), 두개골을 감싸는 둥근 두건(머리 뼈에 붙어 자세에서 벗겨지지 않음, 뒤로 처진 꼭지), 가슴을 덮는 흑자색 로브·벨트·찢긴 단, 큰 활과 시위(왼손), 등의 화살통. 두건 꼭지는 키(HEIGHT)에서 제외.
- 남은 차이: 맞는 자세에서 몽둥이가 가슴 앞으로 올라옴(리그 공통 자세), 모히칸이 옆에서 보면 가닥으로 보임.

### 기사 5종 — 일치 8 / 품질 8, 삼각형 3,762 / 3,856 / 3,572 / 3,602 / 3,846

- 0 일반 기사: 열린 투구(코가리개 막대)·앞으로 휘는 흰 깃·얼굴 보임, 검, 붉은 하트 방패(흰 십자). 1 중갑 기사: 통투구(검은 눈 틈에 노란 눈)·1.45배 두 겹 어깨·넓은 가슴판·가로 금 띠·두꺼운 팔다리 갑옷, 한 단계 어두운 판금, 붉은 깃. 2 창기사: 긴 창(잎 모양 창날·금 깃 테), 붉은 깃. 3 망치 기사: 머리만 한 전쟁 망치, 파란 깃. 4 성기사: 금 테 갑옷·파란 망토(망토 뼈)·파란 방패(금 십자), 붉은 깃.
- 공통: 큰 둥근 투구(금 띠·뺨 가리개), 뒤로 흘러내리는 깃털 다발(깃털 뼈), 은 갑옷·금 테, 1.3배 큰 장화와 넓은 보폭, 검·창·망치는 오른손, 방패는 왼손.
- 리그 제약 때문에 못 한 것: 창을 어깨 위로 세워 들기(공격 충격 위상 검사가 무기 끝이 p≈0에서 가장 낮기를 요구) → 창날을 앞 아래, 자루를 어깨 위로 비스듬히 쥠.

### 기사단장 번쩍경·용사 루루 — 일치 8 / 품질 7, 삼각형 5,714 / 5,865

- 기사단장: 닫힌 강철 면갑(T자 틈 속 빛나는 눈), 짙은 강철 판금에 금 테, 가시 달린 큰 어깨 갑옷, 볏 달린 투구와 붉은 깃, 넓은 붉은 망토, 굵은 대검, 방패 대신 큰 건틀릿(왼손 검사 통과).
- 루루: 한 덩어리 금발(덮개·앞머리 세 갈래·허리까지 뒷머리·옆 가닥·리본), 남색 베레모(금 띠·붉은 깃), 큰 파란 눈·밝은 피부·가는 눈썹, 흰·파랑 드레스와 금 테, 넓은 보라 망토와 브로치, 검, 맨손.
- 남은 차이: 정면에서 기사단장 검이 짧아 보임(원근 단축), 면갑 틈이 진짜 구멍이 아니라 짙은 띠, 루루 뒷머리는 몸(Spine)에 붙어 고개를 돌릴 때 덮개와 분리됨(뒷목 묶음으로 가림).

### 대화 얼굴 아이콘

뿔이(흑자색·노란 세로 동공·왕관·뿔), 기사단장(투구·T자 틈·콧수염), 루루(금발·베레모)를 새 모델에 맞춰 다시 그렸습니다(`UiIcon`). `tests/icon_capture.gd`로 확인.

### 표정

"웃음"(happy) 표정을 눈 감은 미소로 바꿨습니다(눈알을 눌러 감은 눈 선이 보임). 뿔이 환호·무서운 척 끝에 쓰입니다.

## 4. 검증 결과

1. 캐릭터 검사 520개(오크·해골 포함, 관절·발 높이·키·무기 손·충격 위상·표정·예산), 규칙 검사 605개(새 `test_imp_design` 포함), 통합 검사 100개 모두 통과.
2. 심사 점수는 위 표. 1차 워크플로(각 2라운드 보완)에서 6~7.5점에 머문 뒤, 제작자가 고칠 목록을 직접 쓴 보완 라운드로 모두 7~8점으로 올렸습니다.
3. 게임 화면: `docs/screenshots/v0.5/`(출연진 한 줄, 마을의 뿔이·누르기·일꾼, 막사 앞 유닛, 7단계 기사 전투, 보스 전투, 이야기 창 얼굴 3종). `--scenario=showcase`로 다시 찍을 수 있습니다.
4. 성능(데스크톱 소프트웨어 렌더러, 실기기 아님): 캐릭터 삼각형이 늘어(기사 2.8~3.9천 → 3.6~3.9천, 보스 3.1~3.3천 → 5.7~5.9천, 뿔이 2.7~3.0천 → 5.2~6.0천) 최대 부하(10단계 16명) 삼각형이 외곽선 켬 61.9만 → 73.5만, 끔 21.0만 → 24.2만. 회귀 상한 60만은 외곽선 켬에서 넘습니다(4차부터). 대책은 메뉴의 외곽선 끄기와 낮은 FPS 안내이며, 다음 후보는 멀리 있는 캐릭터의 외곽선·세부 생략.

## 5. 남은 생각

- 컨셉 시트의 후보 유닛(슬라임·박쥐 정찰병·버섯 요정, 방패병·사다리병·궁수·수도사·기마병·공병·마법사·성직자)은 아직 규칙도 모델도 없습니다. 같은 빌더 방식으로 추가할 수 있습니다.
- 기사 5종은 지금 `id % 5`로 섞여 나옵니다. 단계마다 구성(예: 창기사는 3단계부터, 성기사는 7단계부터)을 config 로 정하면 적 종류가 늘어나는 느낌을 줄 수 있습니다.
- 캐릭터 재질(림 라이트)은 캐릭터에만 적용했습니다. 건물까지 같은 질감으로 맞출지는 성능과 함께 결정합니다.
