# 개인정보처리방침 (초안)

**앱 이름:** 마물의 작은 마을 (Little Monster Village)
**시행일:** 0000년 00월 00일 (공개할 때 날짜를 넣으세요)
**문의:** (개발자 이메일 주소를 넣으세요)

## 1. 수집하는 개인정보

이 앱은 **어떤 개인정보도 수집하지 않습니다.** 이름, 이메일, 전화번호, 위치, 연락처, 사진, 기기 식별자, 광고 ID, 사용 기록을 수집하거나 서버로 보내지 않습니다.

## 2. 기기 안에만 저장하는 정보

게임을 이어서 하기 위해 다음 정보를 **사용자 기기 안의 앱 전용 저장소**에만 저장합니다.

- 게임 진행 상황: 건물 배치, 꾸미기, 목재, 습격 단계, 공사 남은 시간
- 게임 설정: 음량, 그림자, 안내 완료 여부

이 정보는 기기 밖으로 전송되지 않습니다. 앱을 삭제하거나 *설정 → 앱 → 저장공간 → 데이터 삭제*를 하면 지워집니다. 게임 안 메뉴의 **새 게임**으로도 진행 상황을 초기화할 수 있습니다. 웹(브라우저) 버전은 같은 정보를 브라우저 저장소에 보관하며, 브라우저 데이터를 지우면 삭제됩니다.

## 3. 제3자 제공·광고·결제

이 앱에는 광고, 분석 도구, 로그인, 결제 기능이 없습니다. 제3자에게 제공하는 정보도 없습니다.

## 4. 권한

이 앱(Android)은 인터넷, 위치, 카메라, 마이크, 연락처, 저장소 접근 권한을 요청하지 않습니다.

## 5. 아동의 개인정보

수집하는 개인정보가 없으므로 아동의 개인정보도 수집하지 않습니다.

## 6. 변경

이 방침이 바뀌면 이 페이지에 새 시행일과 함께 알립니다.
