# 첫 플레이 버전 — 검수표와 결과 보고서

이 문서는 제작 AI가 실제 구현을 마친 뒤 사용할 검수 기준입니다. **현재는 제작 지시서와 이미지 자료만 준비한 상태이며, 앱 제작·게임 실행·APK 설치·성능 검증을 수행하지 않았습니다. 아래 항목의 초기 상태는 모두 `미검증`입니다.**

판정은 `통과 / 실패 / 미검증` 중 하나만 사용합니다. 테스트할 기기나 환경이 없으면 이유와 함께 미검증으로 남기고, 에디터 실행·자동 테스트 결과를 실제 휴대전화 검증으로 대신 표기하지 않습니다. 수치와 범위는 통합 제작 지시서를 기준으로 하며, 밸런스 변경은 아래 변경 기록에 남깁니다.

### 완료 보고 기준

플레이 구현 완료를 보고하려면 A01~A22 및 P01~P03의 실패·미검증 항목을 해소하고 APK 빌드 결과를 제출합니다. 실제 Android 기기 검증이 남았다면 **“구현 및 APK 빌드 완료, 실제 기기 검증 미완료”**처럼 범위를 명확히 적습니다. 성능·조작성·출시 준비 완료는 해당 증거 없이 주장하지 않습니다.
