# 마물 마을 — 첫 플레이 버전 제작 묶음

**목표는 Android 휴대전화에 설치해 ‘목재 생산 → 건설·배치 → 인간 기사 방어 → 보상과 다음 습격’을 직접 해보는 작은 게임입니다.**

이 묶음에는 제작 지시서, 규칙, 초기 배치와 수치, 확인 기준, 참고 이미지 10장이 들어 있습니다. 아직 게임 소스나 APK가 들어 있는 것은 아닙니다.

## 제작 AI에 넘기는 방법

1. ZIP을 풀어 제작 AI가 읽을 수 있는 작업 폴더에 넣습니다.
2. 아래 짧은 요청과 함께 **01-AI-BUILD-INSTRUCTIONS.md**를 전달합니다. 파일을 다룰 수 있는 코딩 AI라면 압축을 푼 전체 폴더를 읽게 합니다.
3. 결과로 게임 프로젝트 원본과 Android 설치용 APK, 실행 방법, 실제로 확인한 항목의 보고서를 받습니다.
4. 휴대전화에서 첫 전투까지 해본 다음 조작감과 재미를 조정합니다.

> 이 폴더의 01-AI-BUILD-INSTRUCTIONS.md를 시작점으로 읽고 Android에서 설치·플레이할 수 있는 첫 버전을 제작해줘. 제안서 작성에서 멈추지 말고 프로젝트와 APK를 만들어줘. 이미지들은 외형 참고이므로 개별 건물과 캐릭터를 실제로 조작할 수 있게 구현해줘. 검증 결과와 미검증 항목을 구분해 보고해줘.

## 이번 제작 범위

첫 마을 1개, 건물 4종, 적 1종, 작은 습격 3단계, 건물 이동·추가·방어탑 강화, 목재 자동 생산, 로컬 저장입니다. 온라인 대전·광고·결제·원정 지도는 이후 단계로 남깁니다.

기본 제작 경로는 **Godot 4.x + GDScript + 단순한 실시간 3D**로 제안했습니다. 사용자가 확정한 엔진이라는 뜻은 아닙니다. 우선 입체 모델로 조작과 전투를 완성하고, 참고 이미지의 외형을 점차 맞추도록 했습니다.

숫자와 배치는 테스트를 시작할 기본안입니다. 아직 재미·밸런스·휴대전화 성능을 검증하지 않았습니다.
