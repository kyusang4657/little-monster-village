# 고블린 방어탑 Lv.1 — 제작 AI 전달 자료

## 목적
마물 마을을 지키는 첫 기본 방어시설의 외형 기준 시안입니다. 사용자가 배치 위치를 정하면 사거리 안의 인간 병사 한 명을 자동으로 겨냥하는 단순한 방어탑을 첫 구현 방향으로 제안합니다. 사거리·공격력·공격 간격·건설 비용은 아직 정하지 않았습니다.

불투명 배경의 참고 이미지이며 완성된 3D 모델, 투명 스프라이트, 정확한 제작 도면이나 애니메이션은 아닙니다. 엔진과 2D/3D 구현 방식은 아직 결정하지 않았습니다.

## 고정할 외형
- 지붕 없는 정사각형 목조 망루, 네 개의 굵은 나무 기둥과 네 개의 작은 밝은 돌 받침.
- 꿀빛 갈색 목재, 둥근 모서리, 단순한 대각선 보강재. 기존 주택과 울타리의 재질을 맞춥니다.
- 정면 난간 가운데 보라색 깃발 하나와 밝은 색의 귀여운 마물 해골 문양.
- 사다리는 후면 중앙에 하나. 사다리 위에는 난간 출입구를 두고, 올라오는 길을 가로막는 난간은 만들지 않습니다.
- 발판 중앙 받침 위에 소형 석궁 하나. 기본 자세에서는 깃발이 있는 정면을 향합니다.
- 석궁의 활대와 발사체가 난간에 닿지 않는 높이와 회전 공간을 확보합니다.
- 게임 시점에는 고블린 한 명이 석궁 뒤에서 조작합니다. 고글·초록 피부·보라색 옷은 기존 고블린과 통일하고, 망치는 들지 않습니다.
- 고블린을 제외한 상단·후면 그림은 구조 확인용입니다. 레벨이나 건물 종류가 바뀐 모습으로 해석하지 않습니다.

## 배치와 제작 기준
- 첫 테스트의 논리 점유 면적은 2×2칸입니다. 기둥의 받침과 후면 사다리까지 이 범위 안에 배치합니다.
- 이미지의 점선은 배치 개념 표시입니다. 정확한 치수나 투영 비율 대신 2×2칸이라는 명시 규칙을 기준으로 구현합니다.
- 기준점은 점유 영역의 지면 중앙입니다. 울타리는 기존 설계처럼 격자 변에 놓고, 방어탑은 건물처럼 칸을 점유합니다.
- 탑 몸체는 고정하고 석궁을 회전시킵니다. 고블린도 석궁 뒤 조작 위치를 따라가게 하되, 난간·사다리와 겹치지 않도록 실제 크기를 조정합니다.
- 상단 세 방향과 게임 시점은 생성형 참고 그림이라 세부 비율·난간 높이에 차이가 있습니다. 하나의 모델로 통일하고 회전 여유와 사다리 출입구를 우선 확보합니다.
- 카메라 각도는 아직 확정 수치가 아닙니다. 실제 마을에서 주택·울타리·고블린과 함께 동일한 카메라와 조명으로 확인합니다.
- 별도 파일의 캐릭터와 건물 이미지는 같은 축척이 아닙니다. 운영 고블린이 발판에 서고 석궁에 손을 댈 수 있도록 월드 크기를 맞춥니다.

## 첫 구현 방향
1. 빈 마을에 2×2칸 방어탑을 배치합니다.
2. 인간 기사 한 명이 접근하면 범위 안에서 자동으로 겨냥합니다.
3. 조준 방향으로 석궁이 회전하고 한 발을 발사한 뒤 잠시 기다립니다.
4. 사용자는 전투 중 별도 조작 없이 배치의 효과를 확인합니다.

첫 버전은 이 역할부터 확인합니다. 자동 표적 선택 방식과 수치는 테스트 후 정하고, 업그레이드·다중 공격 등의 추가 기능은 아직 이 이미지에 포함하지 않습니다.

## 제작 방식에 따른 전달 지시
- 3D를 선택하면 탑 몸체, 회전 석궁, 고블린, 발사체를 구분해 제작합니다. 같은 카메라로 모든 기존 자산과 비교하세요.
- 2D를 선택하면 탑 몸체와 회전 무기/조작자 이미지를 구분하고 필요한 방향을 같은 시점에서 제작합니다. 전체 시트의 제목·테두리가 들어가지 않도록 실제 게임용 투명 이미지를 별도로 만드세요.
- 발사·재장전 동작과 발사체 효과는 이 자료에 포함된 완성 애니메이션이 아닙니다.
