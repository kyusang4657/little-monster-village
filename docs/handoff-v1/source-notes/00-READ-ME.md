# 과거 자산 제작 기록

이 폴더는 이미지 생성 당시의 설명과 프롬프트를 원문으로 보존한 기록입니다. 각 파일의 이미지 이름과 ‘다음 단계’ 문구는 당시 개별 패키지를 기준으로 합니다.

이번 통합 묶음의 실제 이미지 경로는 상위 폴더의 asset-manifest.json을 사용하세요. 과거 패키지에 반복해서 들어 있던 비교 이미지는 여기서 중복 복사하지 않았습니다.

현재 게임 규칙은 02-GAME-RULES.md와 config, 외형 기준은 04-ART-GUIDE.md가 우선합니다. 원문에 있는 미확정 엔진·수치·표현 차이를 새 요구로 해석하지 않습니다.
