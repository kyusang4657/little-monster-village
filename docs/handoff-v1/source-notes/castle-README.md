# 마물 성 Lv.1 — 제작 AI 전달 자료

## 목적
마물 마을의 중심 건물인 첫 성의 외형 기준입니다. 기존 마을 전체 시안의 밝은 돌벽·보라색 지붕·청록색 성문을 이어받되, Lv.1에 맞춰 두 개의 작은 탑과 낮은 본관으로 단순화했습니다.

이 파일은 불투명 배경의 참고 시트입니다. 완성된 3D 모델, 투명 스프라이트, 정확한 치수 도면이나 애니메이션은 아닙니다. 엔진과 2D/3D 구현 방식은 아직 정하지 않았습니다.

## 파일
- 01-monster-castle-reference.png: 성의 정면·오른쪽·후면·게임 시점.
- 02-village-style-reference.png: 전체 마을의 색감과 분위기. 이 그림 속 성은 이번 Lv.1보다 복잡하므로 탑 개수와 세부 구조를 그대로 혼합하지 않습니다.
- 03-house-style-reference.png: 기존 주택의 재질과 형태 참고.
- image-prompts.txt: 내장 image_gen 도구에 사용한 생성 프롬프트 원문.

## 외형의 고정 요소
- 낮고 넓은 사각형 본관, 평평한 지붕 테라스와 둥근 성가퀴.
- 정면 양쪽 모서리에 동일한 원형 탑 두 개. 각 탑은 낮은 보라색 원뿔 지붕과 작은 금색 꼭대기 장식이 있습니다.
- 탑을 뒤쪽 모서리로 옮기거나 중앙 탑·후면 탑을 추가하지 않습니다. 뒤쪽의 단순한 돌 모서리 보강부는 지붕 달린 탑이 아닙니다.
- 정면 중앙에 청록색 아치형 양문, 둥근 황동 고리 두 개, 밝은 돌 아치와 낮고 넓은 두 단 계단.
- 성문 위에는 귀여운 뿔 달린 해골 부조 하나.
- 앞쪽 두 탑의 정면에 보라색 세로 깃발을 각각 하나씩 배치합니다. 깃발 위에는 작은 따뜻한 색 창이 있습니다.
- 본관의 양 측면에는 아치형 창 하나씩, 후면에는 아치형 창 두 개. 후면 출입문은 없습니다.
- 지붕 뒤쪽 중앙에 깃대 하나와 작은 보라색 깃발. 깃대는 중앙 탑이 아닙니다.
- 밝은 아이보리 돌벽, 연한 회색 기초, 보라색 지붕, 청록색 문, 소량의 황동 장식과 따뜻한 창빛을 유지합니다.

## 시점을 읽는 방법
- 정면: 성문과 두 개의 전면 탑, 세로 깃발이 보입니다.
- 오른쪽: 건물 정면이 그림의 왼쪽입니다. 가까운 전면 탑 뒤로 본관이 오른쪽으로 이어집니다.
- 후면: 후면 창 두 개가 보이고 성문과 세로 깃발은 가려집니다. 앞쪽 탑 지붕이 뒤에서 일부 보일 수 있습니다.
- 게임 시점: 정면과 오른쪽 측면을 함께 보는 높은 쿼터뷰입니다.

각 그림은 외형 설명용으로 생성한 시안이며 완전히 같은 투영·치수로 렌더링한 도면은 아닙니다. 실제 제작에서는 하나의 모델 또는 공통 기준으로 탑 위치, 창, 성가퀴, 재질을 통일합니다. 정확한 카메라 각도는 기존 주택과 방어탑을 같은 장면에 놓고 맞춥니다.

## 배치 기준
- 첫 테스트의 논리 점유 면적은 3×3칸으로 제안합니다. 기존 주택과 방어탑의 2×2칸보다 큰 중심 건물입니다.
- 기초·앞 계단까지 점유 범위 안에 들어가게 합니다. 점선 그림의 길이를 측정하기보다 명시한 3×3 규칙을 기준으로 구현합니다.
- 기준점은 점유 영역의 지면 중앙입니다.
- 서로 다른 참고 시트는 같은 축척이 아닙니다. 실제 게임에서 주택·울타리·방어탑·고블린과 함께 배치해 크기와 성문 통과 여유를 조정합니다.
- 지붕이 뒤쪽 건물이나 주요 이동로를 지나치게 가리지 않는지 실제 가로 화면에서 확인합니다.

## 첫 구현 역할
이 성은 마을의 중심과 성장 정도를 보여주는 건물로 사용합니다. 첫 구현에서는 마을에 배치하고 눌러 건물 이름과 현재 레벨을 확인하는 정도부터 시작합니다.

업그레이드 조건, 체력, 성이 공격받았을 때의 전투 규칙, 잠금 해제 기능과 비용은 별도 게임 규칙으로 정합니다. 이 그림만으로 전투나 자원 수치를 추정하지 않습니다. 상위 레벨 외형은 이번 자료에 포함하지 않습니다.

## 제작 AI에 전달할 지시
이 시트의 Lv.1 성을 동일한 세계의 주택·방어탑과 함께 배치할 수 있도록 제작하세요. 본관 하나와 앞쪽 원형 탑 두 개의 단순한 구조를 우선 유지하고, 이미지마다 달라 보이는 장식 수는 하나의 기준으로 통일하세요.

- 3D 경로: 하나의 건물 모델을 만들고 지면 중앙 기준점, 3×3 점유 영역, 계단·출입구 위치를 설정합니다.
- 2D 경로: 실제 게임과 동일한 카메라·조명으로 성 한 채를 별도의 투명 PNG로 제작합니다. 참고 시트 전체의 제목·테두리를 게임 자산에 넣지 않습니다.

첫 장면에서 색감·크기·문 위치·주변 가림을 확인한 후 세부 장식과 업그레이드를 진행합니다.
