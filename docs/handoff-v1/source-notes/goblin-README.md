# 고블린 일꾼 Lv.1 — 캐릭터 제작 기준

## 이번 자료

밝고 아기자기한 마물 마을에서 건설을 돕고, 나무 망치로 마을을 방어하는 기본 고블린입니다. 승인한 마을과 주택 시안을 바탕으로 내장 ImageGen을 사용해 만들었습니다.

이번 결과는 **캐릭터 제작을 위한 참고 시트**입니다. 실제 3D 모델·리깅·완성 애니메이션·투명 배경 스프라이트는 아직 포함하지 않습니다. 2D 또는 3D 구현 방식도 아직 확정하지 않았습니다.

## 파일 구성

- `01-goblin-worker-reference.png`: 정면·오른쪽·후면과 게임 시점의 대기·이동·공격 대표 자세. 오른쪽 측면의 망치 손을 수정한 최종 버전입니다.
- `02-village-style-reference.png`: 승인된 마물 마을의 색감·분위기·높은 시점 참고.
- `03-house-scale-reference.png`: 먼저 준비한 2×2칸 고블린 주택. 같은 세계의 재질과 배치 시험에 사용합니다.
- `image-prompts.txt`: 이미지 생성과 수정에 실제 사용한 프롬프트.

## 유지할 디자인

| 항목 | 기준 |
|---|---|
| 자산 이름 | goblin_worker_lv1 |
| 역할 | 기본 주민 및 근접 방어용 마물 |
| 비율 | 큰 머리와 귀, 짧고 둥근 몸통·팔다리. 대략 2.5등신을 출발점으로 삼음 |
| 피부·얼굴 | 밝은 녹색, 따뜻한 갈색 눈, 작은 코, 작은 송곳니, 친근한 표정 |
| 머리 장식 | 갈색 머리카락 한 줌, 이마 위 황동 테두리 고글, 뒤통수의 갈색 가죽 띠 |
| 의상 | 보라색 작업 튜닉, 갈색 벨트와 황동 버클, 베이지색 반바지, 갈색 장화 |
| 도구 | 둥근 직사각형 머리의 짧은 나무 망치 1개. 캐릭터 본인의 오른손에 장착 |
| 접지 기준 | 두 발 사이의 바닥 중심. 이동·대기·공격에서 논리적 원점은 동일하게 유지 |
| 화면 방향 | 마을 시안과 맞는 높은 고정 쿼터뷰. 실제 각도·줌은 배치 시험에서 조정 |
| 크기 | 주택 문으로 들어갈 수 있는 크기. 문 높이의 약 80~90%를 초기 비교값으로 두고 귀·머리 크기와 작은 화면의 가독성을 함께 조정 |

주택과 캐릭터 시트는 같은 축척으로 출력된 실측 도면이 아닙니다. 두 이미지를 그대로 같은 픽셀 높이로 놓지 말고, 실제 시험 장면에서 크기를 맞춥니다.

## 동작의 의미

- **대기:** 편안히 서서 망치를 오른손 옆에 듭니다. 실제 애니메이션에서는 작은 호흡과 눈 깜빡임을 넣을 수 있습니다.
- **이동:** 걸음의 한 순간을 보여주는 자세입니다. 완성된 걷기 동작에는 발이 앞으로 나갔다가 반대 발과 교대하는 연속 동작이 필요합니다.
- **공격:** 망치를 들어 올린 공격 준비 자세입니다. 실제 공격은 준비 → 내려치기 → 타격 → 복귀로 연결합니다. 시트 한 장에 이 전체 과정이 들어 있는 것은 아닙니다.

## 제작 AI에게 전달할 첫 작업

고블린 외형을 위 디자인으로 유지하고, 앞서 준비한 주택 옆에서 대기·이동을 시험할 수 있는 캐릭터를 만들어 주세요. 먼저 프로젝트의 엔진과 2D/3D 경로를 확인하세요.

- **3D로 제작할 경우:** 단순한 모델과 관절 구조를 준비하고, 망치를 오른손에 붙이는 별도 도구로 다룹니다. 머리·귀·고글과 몸통의 비율을 유지합니다. 완성 동작은 동일한 모델에서 제작하고, 두 발 사이 바닥 중심을 배치 기준으로 삼습니다.
- **2D로 제작할 경우:** 게임 카메라 방향에 맞는 투명 배경 이미지와 필요한 방향별 연속 프레임을 준비합니다. 그림의 빈 여백이 달라도 각 프레임에서 발 기준점과 캐릭터 크기가 흔들리지 않게 합니다. 이 시트 전체를 그대로 스프라이트 시트로 사용하지 않습니다.
- **공통:** 문자·패널 테두리·흰 배경·시트 그림자는 캐릭터 소재에 포함하지 않습니다. 그림자 표현은 엔진에서 별도로 맞춥니다. 이동 속도·충돌 크기·공격 판정은 코드와 데이터로 정합니다.

## 확인할 사항

1. 주택 문과 캐릭터의 크기가 자연스럽게 맞는가.
2. 집 앞과 뒤를 지나갈 때 가림 순서가 올바른가.
3. 이동할 때 발이 땅에서 뜨거나 캐릭터 크기가 흔들리지 않는가.
4. 방향이 바뀌어도 망치는 본인의 오른손에 있는가.
5. 공격 준비·타격·복귀와 실제 공격 판정 시점이 일치하는가.
6. 작은 모바일 화면에서도 녹색 얼굴·고글·보라색 의상·망치가 구분되는가.
