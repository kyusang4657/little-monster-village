# 고블린 주택 Lv.1 — 첫 제작 기준 이미지

## 이 자료의 용도

밝고 아기자기한 마물 마을 게임에 사용할 첫 건물의 디자인 기준입니다. 동일한 주택의 정면·오른쪽·후면·게임 시점을 보여줍니다. 작은 주택으로 크기, 시점, 격자 배치와 앞뒤 가림을 시험한 뒤 성·생산시설·울타리로 확대합니다.

이 자료는 **제작 참고용 콘셉트 시트**입니다. 아직 게임에 바로 넣는 투명 스프라이트, 실제 3D 모델, 실행 가능한 게임은 만들어지지 않았습니다. 2D와 3D 중 최종 구현 방식은 미정입니다.

## 전달할 파일

- `01-goblin-house-reference.png`: 이번 주택의 4방향 기준 시안. 후면에서 굴뚝이 왼쪽에 보이도록 방향 일관성을 수정한 버전입니다.
- `02-approved-village-direction.png`: 사용자가 승인한 마을 전체 시안. 전체 분위기·색감·높은 시점을 참고합니다. 게임 UI나 모든 건물을 함께 구현하라는 뜻은 아닙니다.
- `image-prompts.txt`: 내장 ImageGen으로 사용한 원본 생성 프롬프트와 후면 수정 프롬프트입니다.

## 제작 AI에게 전달할 첫 작업 요청

첨부한 두 이미지를 참고해 고블린 주택 한 채를 작은 격자 바닥에 배치하는 시험 장면을 만들어 주세요. 우선 기존 프로젝트의 엔진과 도구를 확인해 2D 또는 3D 경로를 선택하고 이유를 설명해 주세요. 전체 마을이나 상점·결제·전투를 한 번에 구현하지 말고, 아래의 배치 검증이 가능한 범위부터 진행해 주세요.

- **2D 경로**: 오른쪽 아래 게임 시점을 기준으로 별도의 투명 배경 건물 소재를 준비합니다. 시트 전체나 글자가 포함된 이미지를 그대로 게임 오브젝트로 사용하지 않습니다. 배치 기준점을 바닥 점유 중심에 맞추고, 앞뒤 정렬과 캐릭터가 지나갈 공간을 확인합니다. 최종 해상도와 그림자 처리 방식은 목표 화면 크기에서 정합니다.
- **3D 경로**: 시트와 명세를 참고해 단순한 입체 모델을 제작합니다. 이미지가 자동으로 3D 모델이 되었다고 취급하지 않습니다. 엔진의 수직축에 맞춰 바닥 점유 중심을 원점으로 잡고, 기본 건물은 고정된 평행투영 카메라로 봅니다. 카메라 높이는 약 55도, 수평 회전은 약 45도를 출발점으로 삼아 전체 마을 시안과 맞춥니다. 정확한 각도는 시험에서 조정합니다.
- **공통 배치 동작**: 터치/드래그로 이동하고 손을 떼면 격자에 맞춥니다. 다른 건물이나 맵 밖과 겹칠 때 설치를 막습니다. 설치 가능/불가능 미리보기를 구분합니다.

## 첫 검증의 완료 기준

1. 같은 집을 여러 채 놓았을 때 시점·크기·바닥 접점이 일관됩니다.
2. 2×2 점유 영역과 실제 보이는 건물이 자연스럽게 맞습니다.
3. 드래그 배치, 격자 맞춤, 설치 불가 위치 처리가 동작합니다.
4. 집 뒤와 앞을 오가는 임시 캐릭터로 가림 순서를 확인합니다.
5. 작은 모바일 화면에서도 문·지붕·창문이 구분됩니다.

이후 같은 비율로 기본 마물 1종의 대기·이동·공격 모습을 준비해 움직임을 시험합니다. 결과를 확인한 뒤 다음 건물과 울타리 제작 규격을 확정합니다.
