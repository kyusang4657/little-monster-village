# 방어 모드 v1 — 제작 AI 전달 자료

## 화면의 의미
초반 마물 마을에 인간 기사 네 명이 접근하고, 고블린 방어탑 두 개가 자동으로 공격하는 전투 중 화면 시안입니다. 기존 마을과 같은 가로 화면·높은 쿼터뷰·밝고 둥근 재질을 사용합니다.

정적인 이미지이며 실제 이동, 표적 선택, 발사체, 피해 판정, 승패 처리가 구현되거나 테스트된 게임 화면은 아닙니다. 기사 수와 체력 막대 상태는 이 시안을 위한 예시입니다.

## 화면 구성
- 왼쪽 위: 방패 아이콘과 ‘첫 번째 습격’.
- 위쪽 중앙: 인간 투구 아이콘과 ‘남은 적 4’.
- 오른쪽 위: 일시정지 버튼.
- 왼쪽 아래: ‘방어탑이 자동으로 공격합니다’라는 안내. 누르는 스킬 버튼이 아닌 상태 설명입니다.
- 적 머리 위: 작은 빨간 체력 막대. 아군과 적은 초록·보라 대 은색·빨강 외형으로도 구분합니다.

건설 격자·이동 미리보기·건물 배치 버튼은 전투 중 숨깁니다. 불필요한 자원 수치·광고·영웅 스킬·조이스틱은 이번 시안에 넣지 않았습니다.

## 장면과 외형
- 성 1채, 주택 2채, 벌목소 1채, 방어탑 2개를 평상시 위치에 유지합니다.
- 기사 네 명이 아래쪽 길에서 등장해 열린 정문을 통과하고 성 쪽으로 이동합니다. 두 명은 문 안쪽, 두 명은 바깥 접근로에 보입니다.
- 첫 전투 예시에서는 정문을 열린 상태로 둡니다. 문 파괴·성벽 공성 규칙을 이 이미지로 확정하지 않습니다.
- 모든 기사는 같은 Lv.1 모델입니다. 은색 갑옷, 붉은 깃·망토·방패, 오른손 검과 왼손 방패를 유지합니다.
- 마을로 들어가는 방향이므로 기사들의 뒤쪽과 붉은 망토가 주로 보입니다.
- 방어탑 몸체는 고정하고 석궁과 조작자의 방향을 목표 쪽으로 맞춥니다. 왼쪽 탑은 화면 오른쪽, 오른쪽 탑은 화면 왼쪽의 접근 기사들을 겨냥합니다.
- 화살 두 개와 작은 궤적·피격 반짝임으로 자동 공격을 표현합니다. 건물은 모두 온전한 상태입니다.
- 지상 고블린 일꾼은 전투 통로 옆에 서 있습니다. 이 시안에 근접 전투 능력을 새로 추가한 것은 아닙니다.

## 첫 구현의 흐름 제안
1. 플레이어가 습격 예고를 확인하고 준비 후 전투를 시작합니다. 예고 화면은 이번 이미지에 포함하지 않았습니다.
2. 기사들이 입구를 통해 접근하고, 방어탑은 범위 안의 적을 자동으로 선택해 공격합니다.
3. 적이 피해를 받으면 체력 막대가 줄고, 전투에서 제거되면 남은 적 수가 갱신됩니다.
4. 남은 적을 모두 막으면 승리 결과로 넘어갑니다. 결과·보상 화면은 별도 제작 대상입니다.

이 예시는 작은 자동 방어 전투를 확인하기 위한 시작점입니다. 수동 스킬 없이 방어탑 배치의 효과부터 확인하는 방향을 제안합니다. 랜덤 습격 간격, 적 수, 공격력, 사거리, 발사 간격, 성의 체력, 실패 조건과 보상은 아직 확정하지 않았습니다.

## 구현 시 연결할 규칙
- 기사 수 표시는 실제 살아 있는 적 데이터에 연결합니다. 이후 적이 순차 등장하는 방식을 쓰면 대기 중인 적을 집계하는지 따로 정합니다.
- 공격의 출발점과 석궁의 조준 방향, 발사체의 진행 방향을 일치시킵니다. 그림 속 궤적 길이를 사거리 수치로 해석하지 않습니다.
- 기존 울타리와 건물의 충돌을 고려해 경로를 계산합니다. 길을 따라 이동하는 그림 자체가 경로 탐색 검증은 아닙니다.
- 적의 목표 선택과 막힌 길 처리, 성에 도달했을 때의 행동은 플레이 규칙으로 명시해야 합니다.
- 일시정지는 적 이동과 공격 등 전투 시간을 함께 멈추고, 계속하기로 같은 상태를 재개하는 동작을 제안합니다.
- 일꾼과 기사는 각자의 문을 통과할 수 있는 같은 월드 축척으로 제작합니다. 개별 시트의 이미지 크기는 실제 키 비율이 아닙니다.
- 패배 후 마을을 영구 삭제하는 규칙은 추가하지 않습니다. 마을을 계속 발전시키는 기존 방향을 유지합니다.

## 제작 AI에 전달할 지시
평상시 마을의 독립된 건물과 캐릭터를 그대로 사용하고 전투 상태를 추가하세요. 화면 전체를 배경 그림으로 사용하는 대신 적 이동, 방어탑의 회전, 발사체, 체력 표시, 남은 적 수와 일시정지를 각각 실제 기능으로 연결하세요.

첫 단계에서는 같은 기사 네 명과 방어탑 두 개로 이동·자동 표적 선택·공격·제거·전투 종료를 확인합니다. 외형의 세부는 동봉한 기준 시트를 우선하며, UI 글자는 실제 텍스트로 표시합니다. 구현 엔진과 2D/3D 방식은 아직 정하지 않았습니다.

## 생성 기록
내장 image_gen 도구를 사용했습니다. 평상시 마을과 기사·방어탑·고블린 기준 시트를 참조해 전투 화면을 만든 뒤, 왼쪽 석궁의 조준 방향과 화살 궤적 표현을 수정한 결과를 선택했습니다. 프롬프트 원문은 image-prompts.txt에 있습니다.
