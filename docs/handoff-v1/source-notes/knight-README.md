# 인간 기사 Lv.1 — 제작 AI 전달 자료

## 이 자료의 목적
마물 마을에 침입하는 기본 인간 근접 병사의 외형과 동작 방향을 정하기 위한 기준 시안입니다. 가로 화면, 높은 고정 쿼터뷰, 밝고 아기자기한 마을 건설·방어 게임의 기존 고블린과 같은 세계에 등장합니다.

이미지는 불투명 배경의 참고 시트입니다. 완성된 3D 모델이나 투명 스프라이트, 연속 애니메이션 프레임은 아닙니다. 사용할 엔진과 2D/3D 구현 방식은 아직 결정하지 않았습니다.

## 파일
- 01-human-knight-reference.png: 최종 기사 기준 시트. 정면·오른쪽·후면, 게임 시점의 대기·이동·공격 대표 자세.
- 02-goblin-comparison-reference.png: 아군 고블린의 재질, 비율, 진영 대비 참고.
- 03-village-style-reference.png: 마을의 전체 색감과 화면 방향 참고.
- image-prompts.txt: 내장 이미지 생성 도구로 사용한 최초 생성 프롬프트와 측면 손 위치 수정 프롬프트.

## 유지할 외형
- 큰 머리와 짧고 통통한 팔다리, 약 2.5~3등신. 복잡한 금속 표면보다 둥근 형태를 우선합니다.
- 사람 피부색과 둥근 귀, 갈색 눈. 고블린의 초록 피부·송곳니·뾰족한 귀·고글을 적용하지 않습니다.
- 은색 투구와 갑옷, 적은 양의 황동 테두리, 붉은 깃 장식 하나와 짧은 붉은 망토, 붉은 허리 천, 갈색 장갑과 장화.
- 검은 항상 캐릭터 본인의 오른손, 둥근 붉은 방패는 왼손에 고정합니다.
- 정면에서 검은 화면 왼쪽, 후면에서 검은 화면 오른쪽입니다. 오른쪽 측면에서는 가까운 팔이 검을 잡고, 먼 쪽 방패는 몸에 가려질 수 있습니다.
- 깃 장식과 망토가 높은 시점에서도 붉은 인간 진영을 식별하게 합니다. 아군의 초록·보라와 대비를 유지합니다.
- 한 레벨의 동일 인물이므로 모든 방향에서 투구, 갑옷, 검, 방패, 장식 수와 비율을 통일합니다. 생성 시트의 미세한 차이는 별도 장비로 해석하지 않습니다.

## 동작과 크기
- 대기: 검과 방패를 들고 잠시 서 있는 상태.
- 이동: 한 발을 내딛는 대표 자세. 이 한 장으로 걷기 애니메이션이 완성되는 것은 아닙니다.
- 공격: 오른손 검을 들어 올린 공격 준비 자세. 실제 제작에서는 휘두르기·타격·복귀 구간을 추가합니다.
- 피격·퇴각/소멸 등의 실제 게임 동작은 추후 별도로 제작합니다.
- 그림 속 패널 크기는 실제 월드 크기를 뜻하지 않습니다. 고블린과 같은 장면에 세워 기사 키를 약간 크게 시작하되, 마을·문·울타리와 함께 화면에서 확인해 조정합니다.
- 캐릭터 기준점은 양발 사이 지면 중심으로 잡습니다. 모든 동작과 방향에서 크기와 기준점이 흔들리지 않게 합니다.
- 하단은 게임 시점의 방향 참고입니다. 정확한 카메라 수치가 검증된 투영도는 아닙니다. 실제 마을 카메라에 맞춰 고블린과 기사 모두 동일한 시점과 조명으로 제작합니다.

## 제작 AI에 전달할 지시
이 자료를 기준으로 기본 적 병사 '인간 기사 Lv.1'을 구현하세요. 우선 기존 고블린과 함께 마을 화면에 배치해 색상 구분, 크기, 발 위치, 검과 방패의 손 위치를 확인하세요. 아래 제작 경로는 프로젝트에서 정한 방식 한 가지를 적용하세요.

- 3D 경로: 하나의 모델과 리그를 만들고 오른손에 검, 왼손에 방패를 연결합니다. 상단 세 방향은 모델링 참고, 하단은 동작 참고로 사용합니다.
- 2D 경로: 같은 기준 모델·카메라로 필요한 방향과 동작을 별도 투명 PNG로 제작합니다. 좌우 반전으로 방향을 늘리면 검과 방패의 손이 바뀌므로 그대로 사용하지 않습니다.

전체 시트의 제목과 테두리가 게임 화면에 들어가지 않도록, 실제 게임용 자산은 별도로 제작하세요. 공격 범위·체력·속도 등 수치는 이 이미지에서 추정하지 말고 첫 전투 테스트에서 정하세요.
