# 건설 모드 v1 — 제작 AI 전달 자료

## 화면의 의미
기존 주택 한 채를 옮기는 중인 가로 화면 시안입니다. 오른쪽 주택을 선택해 빈 확장 공간으로 끌어 놓고, 배치를 확정하기 전의 상태를 표현했습니다. 새 주택을 구매하거나 건설하는 화면은 아닙니다.

이미지는 내장 image_gen 도구로 만든 정적인 UI 참고 화면입니다. 실제로 터치·이동·회전·충돌 검사가 구현된 프로그램은 아닙니다.

## 파일
- 01-build-mode-reference.png: 최종 건설 모드 이미지.
- 02-village-before-moving.png: 이동 전 마을 배치.
- 03-house-reference.png: 동일 주택의 외형 기준.
- image-prompts.txt: 사용한 최초 생성 및 점유 영역 정렬 수정 프롬프트.

## 화면 구성
- 왼쪽 위: 망치 아이콘과 ‘건설 모드’.
- 위쪽 중앙: ‘집을 끌어 원하는 곳에 놓으세요’.
- 오른쪽 빈 잔디: 반투명 주택 하나, 초록색 선택 윤곽과 점유 영역.
- 주택 위: 체크 아이콘과 ‘배치 가능’.
- 하단 정보: ‘고블린 주택 · Lv.1’, ‘2×2칸 · 이동 중’.
- 하단 버튼: ‘취소’, ‘회전’, ‘배치’. 배치 버튼을 가장 눈에 띄게 합니다.

밝은 아이보리 패널, 짙은 보라색 글자, 보라색 회전 버튼과 초록색 배치 버튼을 사용합니다. 가격·구매·건설 시간은 이 화면에 표시하지 않습니다.

## 이동 흐름 제안
1. 건설 모드에서 기존 주택을 선택하면 원래 위치와 방향을 보관하고 이동 미리보기를 시작합니다.
2. 선택한 주택을 끌면 지면의 격자에 맞춰 미리보기가 이동합니다. 선택 주택과 주변에만 격자를 표시합니다.
3. 배치 가능한 위치에서는 초록색 영역과 체크 아이콘, ‘배치 가능’을 보여줍니다.
4. ‘회전’을 누르면 제자리에서 90도씩 방향을 바꿉니다. 문·창·굴뚝을 포함한 건물 전체가 함께 회전합니다.
5. ‘배치’를 누른 순간에만 새 위치와 방향을 확정하고 이동 모드를 종료합니다.
6. ‘취소’를 누르면 원래 위치와 방향으로 돌아가며 변경을 저장하지 않습니다.

이 흐름은 첫 구현을 위한 제안입니다. 이동 전에 원래 집을 삭제한 뒤 새 집을 생성하는 방식으로 처리하지 말고, 같은 건물의 미리보기와 확정 상태를 구분하세요.

## 선택과 조작 규칙
- 화면에는 고정 주택 한 채와 이동 미리보기 한 채, 총 두 채만 보입니다. 원래 오른쪽 자리에는 같은 집의 복사본이나 잔상을 남기지 않습니다.
- 성·벌목소·방어탑·울타리는 이동하지 않습니다.
- 선택한 집을 드래그하면 건물을 이동하고, 빈 배경을 드래그하면 카메라를 움직이도록 구분할 수 있습니다. UI 버튼 터치는 뒤의 지면에 전달하지 않습니다.
- 버튼 간격과 실제 터치 영역은 작은 휴대전화에서도 누르기 편한지 확인합니다. 이미지에서의 픽셀 크기를 모든 기기에 그대로 적용하지 않습니다.
- 하단 패널이 선택한 집을 가릴 경우 카메라나 패널 위치를 조정합니다. 화면 안전 영역도 고려합니다.

## 점유 영역과 배치 판정
논리적 주택 점유 면적은 2×2칸입니다. 초록색 표시에는 기초와 계단을 포함한 실제 점유 영역이 대응해야 합니다. 생성 그림의 선이나 픽셀을 측정해서 칸 크기를 정하지 말고, 실제 구현 격자와 건물 기준점으로 계산합니다.

다른 건물·울타리·맵 경계 등과 겹치는지를 실제 데이터로 검사합니다. 이 참고 이미지의 초록색 표시는 배치 가능 상태를 표현한 것이며, 검사 결과가 검증된 화면은 아닙니다.

배치 불가 상태는 이번 그림에 포함하지 않았습니다. 구현 시에는 색상만 바꾸지 말고 금지 아이콘·짧은 이유 문구와 비활성화된 배치 버튼을 함께 사용합니다. 예시 문구는 ‘다른 건물과 겹칩니다’입니다.

기존 길은 이동 미리보기 중 자동으로 따라가지 않습니다. 새 위치의 도로 연결을 필수 조건으로 삼을지는 별도로 정해야 합니다. 이미지에서 ‘배치 가능’이라고 표시된 것은 도로 연결 규칙까지 확정했다는 뜻이 아닙니다.

## 실제 자산과 UI 제작
전체 화면 이미지를 하나의 조작 불가능한 배경으로 사용하는 대신 건물·지형·선택 표시·버튼·문구를 별도 요소로 구성합니다. 주택의 재질과 외형은 03-house-reference.png를 따릅니다.

- 3D 경로에서는 같은 모델을 회전하고 선택 표시를 지면에 정렬합니다.
- 2D 경로에서는 필요한 방향의 별도 이미지를 제작합니다. 좌우 반전은 굴뚝·출입구 위치가 바뀌므로 건물의 90도 회전과 같지 않습니다.
- 주택 반투명도와 초록 윤곽은 선택 상태 효과이며, 기본 주택 재질을 영구 변경하지 않습니다.
- 한국어 문구는 이미지에 구워 넣지 말고 실제 UI 텍스트로 표시합니다.
- 엔진과 2D/3D 구현 방식은 아직 결정하지 않았습니다.

## 생성 기록
이동 전 마을 이미지와 주택 기준 시트를 참조해 건설 모드 화면을 생성했습니다. 첫 결과에서 주택 앞쪽으로 과하게 뻗은 초록색 점유 표시를 줄여 기초 아래에 맞춘 결과를 최종 선택했습니다. 프롬프트 원문은 image-prompts.txt에 있습니다.
