# 초반 마을 전체 화면 v1 — 제작 AI 전달 자료

## 이번 결과
기존에 만든 건물을 한 화면에 모은 초반 마을 배치 시안입니다. 가로 16:9 구도, 높은 쿼터뷰, 밝고 둥근 장난감 같은 3D 표현을 사용합니다.

전체 이미지에서는 건물 사이의 여유, 통로, 마을 분위기를 참고하고, 건물의 정확한 외형은 함께 넣은 개별 기준 시트를 우선합니다. 실제 엔진에서 구동하거나 배치 충돌을 검사한 화면은 아닙니다.

## 건물 구성

| 종류 | 수량 | 첫 구현 점유 면적 | 전체 이미지에서의 위치 |
| --- | ---: | --- | --- |
| 마물 성 Lv.1 | 1 | 3×3칸 | 뒤쪽 중앙 |
| 고블린 주택 Lv.1 | 2 | 각 2×2칸 | 중앙 통로 양옆 |
| 고블린 벌목소 Lv.1 | 1 | 2×2칸 | 왼쪽 뒤 |
| 고블린 방어탑 Lv.1 | 2 | 각 2×2칸 | 앞쪽 출입문 양옆 안쪽 |

건물은 총 여섯 동입니다. 나무·바위·풀은 주변 장식이며 새로운 생산 건물이 아닙니다. 성은 앞쪽 원형 탑 두 개와 평평한 본관만 있는 Lv.1 디자인을 유지합니다.

## 마을 배치 방향
- 한 겹의 낮은 나무 울타리가 마을을 둘러쌉니다. 중앙 앞쪽에 열린 양문 출입구 하나를 둡니다.
- 출입문에서 성문까지 이어지는 중심 길과 주택·벌목소를 잇는 가지 길이 있습니다.
- 방어탑은 출입문 통로를 막지 않게 안쪽 양옆에 둡니다.
- 벌목소는 왼쪽 뒤에 배치합니다. 초기 생성 프롬프트에는 앞쪽 배치 요청이 있으나, 최종 화면에서는 왼쪽 뒤로 잡혔으므로 이 문서와 최종 이미지를 기준으로 읽습니다.
- 오른쪽 빈 잔디에는 추가 건물을 지을 공간을 남깁니다. 옅은 격자 표시는 확장 가능 구역을 설명하는 시각적 예시입니다.
- 주변 나무와 바위는 울타리 밖을 중심으로 배치합니다. 건물 출입구와 주요 통로를 가리지 않습니다.

## 격자와 크기
14×10칸 정도의 내부 건설 구역을 첫 구현 출발점으로 제안합니다. 이 수치와 각 건물의 점유 면적은 구현 규칙 제안이며, 생성 이미지의 기둥 개수·픽셀 길이·격자를 측정해 확인된 치수가 아닙니다.

- 울타리 직선은 격자 변을 따라 1칸, 출입문은 2칸 폭입니다. 기둥은 꼭짓점에서 공유해 겹치지 않게 합니다.
- 건물의 돌 받침과 계단·사다리는 지정한 점유 범위 안에 수용합니다.
- 실제 배치에서는 문에서 길로 나갈 공간, 건물끼리의 가림, 고블린이 통과할 폭을 확인합니다.
- 고블린은 주택 문으로 들어갈 수 있는 크기를 기준으로 맞춥니다. 탑 위 조작자와 지상 일꾼도 같은 월드 축척을 사용합니다.
- 이미지가 건물마다 완벽히 같은 축척을 보장하지는 않습니다. 실제 자산을 한 장면에 놓고 조정합니다.

## 외형 기준
- 성: 낮은 아이보리 본관, 보라색 원뿔 지붕 두 개, 청록색 성문.
- 주택: 보라색 맞배지붕, 밝은 벽, 갈색 목재, 정면의 둥근 다락창.
- 벌목소: 뒤가 높고 앞이 낮은 외쪽지붕, 열린 양 측면, 정면 왼쪽 작업대와 오른쪽 통나무 세 개.
- 방어탑: 지붕 없는 나무 발판, 석궁 하나, 보라색 깃발, 고블린 조작자.
- 울타리: 둥근 모서리의 나무 기둥과 두 개의 가로 난간.
- 고블린: 초록 피부, 큰 귀, 이마의 황동 고글, 보라색 옷.

이 전체 화면은 개별 자산을 다시 그린 합성 시안입니다. 굴뚝·사다리·석궁·작업대 같은 세부가 개별 시트와 다르면 개별 시트의 고정 구조를 우선 적용합니다.

## 제작 AI에 전달할 지시
이 자료를 참고해 여섯 동의 건물을 배치한 초기 마을 장면을 구성하세요. 전체 그림은 카메라·배치·색감 참고로 사용하고, 건물은 각각의 기준 이미지에 따라 독립적으로 제작하세요. 이 그림 한 장을 배경으로 깔아 건물을 움직일 수 없게 만드는 방식은 마을 건설 기능의 완성으로 간주하지 않습니다.

우선 기존 자산만으로 다음을 확인하세요.
1. 성과 주택, 벌목소, 방어탑이 같은 조명과 축척으로 보이는지.
2. 건물을 선택할 수 있고 배치 시 서로 겹치지 않는지.
3. 출입문에서 성·주택까지 길이 연결되고 이동 공간이 확보되는지.
4. 화면을 축소했을 때도 건물 종류와 빈 건설 공간을 구분할 수 있는지.

엔진과 2D/3D 방식은 아직 결정하지 않았습니다. 실제 카메라 각도, 맵 좌표, 이동 경로, 충돌 영역은 구현에서 확정해야 합니다. 이번에는 배치 확인을 위해 UI를 생략했으며, 자원 수치·버튼·튜토리얼·전투 규칙은 이 이미지에 포함하지 않았습니다.

## 생성 기록
내장 image_gen 도구를 사용했습니다. 최초 생성 시에는 성·주택·벌목소·방어탑·울타리 다섯 시트를 참조했습니다. 고블린은 방어탑 시트의 조작자를 외형 참고로 사용했고, 개별 고블린 시트는 제작용 보충 자료로 함께 넣었습니다.

첫 결과에서 카메라를 더 멀리 조정해 울타리 네 모서리가 모두 들어오는 최종 결과를 선택했습니다. 생성 프롬프트의 수치와 외형 요구가 모두 정확히 구현됐다는 의미는 아닙니다.
