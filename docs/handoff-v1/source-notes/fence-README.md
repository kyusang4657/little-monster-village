# 나무 울타리 Lv.1 — 모듈 제작 기준

밝고 귀여운 마물 마을에서 플레이어가 구역과 통로를 만들 때 사용하는 초기 목재 울타리입니다. 내장 ImageGen으로 직선·모서리·끝기둥·문의 열림/닫힘과 연결 예시를 만들었습니다.

**제작 참고용 시트**이며, 정확한 실측 도면이나 게임에 즉시 넣을 3D 모델·투명 스프라이트·문 애니메이션은 아닙니다. 게임에서의 격자 배치와 충돌 기능도 아직 구현하지 않았습니다. 구현 방식은 미정입니다.

## 포함 파일

- `01-wooden-fence-reference.png`: 직선 B의 방향을 수정한 최종 기준 이미지.
- `02-village-style-reference.png`: 승인된 전체 마을 시안.
- `03-house-style-reference.png`: 목재·색감과 같은 세계의 건물 스타일 참고.
- `image-prompts.txt`: 실제 이미지 생성 및 수정 프롬프트. 과거 생성 기록이며, 구현 규격은 이 문서를 우선합니다.

## 부품과 역할

| 부품 | 첫 시험용 규격 |
|---|---|
| 직선 A / B | 길이 1단위의 동일 울타리를 서로 다른 격자 축 방향으로 놓은 모습. 3D에서는 같은 모델을 수평으로 90도 회전 |
| 모서리 | 같은 직선 2개를 직각으로 연결. 모서리 기둥을 1개만 공유 |
| 끝기둥 | 울타리 줄이 끝나는 지점의 마감 기둥 |
| 출입문 | 너비 2단위. 양쪽 외곽 기둥의 경첩으로 문짝 2개를 열고 닫음. 통로 중앙에는 고정 기둥을 두지 않음 |
| 연결 예시 | 부품을 이어 구역을 만드는 모습을 설명하는 참고 그림. 이미지의 길이나 기둥 간격을 픽셀로 측정해 모델 치수로 사용하지 않음 |

## 격자와 연결 기준 — 시제품 제안

- 격자 한 변을 1단위로 정합니다. 먼저 만든 주택은 2×2칸을 점유합니다.
- 첫 시험에서는 울타리를 **격자 경계선 위에 배치**합니다. 기둥 중심은 격자 꼭짓점에, 가로목은 이웃 꼭짓점 사이에 둡니다. 건물처럼 칸 전체를 차지하는 규칙과 혼용하지 않습니다.
- 기둥과 가로목은 재사용 가능한 별도 요소로 다룹니다. 연결 지점마다 기둥을 1개만 생성해 중복 기둥이나 틈을 막습니다.
- 2칸 출입문을 놓으면 그 구간의 일반 가로목과 중앙 기둥은 제거합니다. 문 양쪽 기둥은 이웃 울타리와 공유합니다.
- 정중앙 출입문을 시험하려면 **가로 6단위 × 세로 3단위 사각형**을 사용합니다. 앞쪽 변은 직선 2개 + 2단위 문 + 직선 2개로 구성합니다. 이 수치가 배치 시험 기준이며 시트의 연결 예시는 구도를 설명합니다.
- 전체 높이는 고블린의 가슴~어깨 높이부터 비교합니다. 실제 크기는 주택·캐릭터와 함께 놓아 조정합니다.
- 울타리의 목재 색, 기둥 굵기, 가로목 높이는 모든 부품에서 동일하게 유지합니다.

## 제작 AI에게 전달할 첫 작업

첨부한 시트를 바탕으로 직선 울타리 1구간과 기둥, 2단위 출입문을 제작하고 작은 격자 바닥에서 연결을 시험해 주세요. 게임 전체를 한 번에 구현하지 말고 아래의 최소 배치를 먼저 완성해 주세요.

1. 직선으로 이어진 울타리 3구간을 배치합니다.
2. 한 구간을 직각으로 연결해 모서리에서 기둥이 겹치지 않는지 확인합니다.
3. 6×3 구역을 구성하고 앞쪽 중앙에 출입문을 넣습니다.
4. 문을 열면 통로로 이동하고 닫으면 돌아가는 임시 캐릭터를 놓습니다.

- **3D 경로:** 가로목·기둥·문짝을 구분하고 문짝의 회전 중심을 경첩 위치에 둡니다. 카메라와 광원은 주택·고블린과 동일하게 맞춥니다.
- **2D 경로:** 게임 시점과 조명을 통일한 방향별 투명 소재가 필요합니다. 직선 B를 A 이미지의 단순 평면 회전으로 대체하지 않습니다. 문자·패널·바닥 안내선을 실제 소재에 넣지 않습니다. 문 패널은 동작 구조 참고이며 최종 게임 이미지는 동일한 게임 카메라로 다시 준비합니다.
- **공통:** 가로목 사이가 시각적으로 비어 있어도 닫힌 울타리 구간은 이동 경계로 처리합니다. 열린 문에는 보이지 않는 중앙 장애물이 남지 않아야 합니다. 실제 방어 내구도·공격·파괴 규칙은 이후 전투 시험에서 정합니다.

## 완료 기준

- 양쪽 격자 축에서 길이와 높이가 같습니다.
- 직선과 모서리에서 이음새가 맞고 기둥이 중복되지 않습니다.
- 문이 열려도 외곽 기둥 위치는 움직이지 않습니다.
- 문 열림·닫힘 상태와 이동 가능 여부가 일치합니다.
- 주택 출입구·길·캐릭터가 함께 놓였을 때 크기와 통로 폭이 자연스럽습니다.

이 규격은 첫 연결 시험을 위한 제안입니다. 마을 배치와 이동 시험 후 칸 점유 방식 등 최종 규칙을 확정할 수 있습니다.
