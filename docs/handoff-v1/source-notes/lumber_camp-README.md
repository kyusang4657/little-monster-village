# 고블린 벌목소 Lv.1 — 제작 AI 전달 자료

## 목적
마물 마을의 건설 재료인 목재를 생산하는 초기 건물의 외형 기준입니다. 기존 주택과 구분되도록 열린 작업장, 한쪽으로 기울어진 보라색 지붕, 밝은 통나무 단면을 중심으로 디자인했습니다.

불투명 배경의 제작 참고 시트입니다. 완성된 3D 모델, 투명 스프라이트, 정확한 투영 도면이나 작동 애니메이션은 아닙니다. 구현 엔진과 2D/3D 방식은 아직 결정하지 않았습니다.

## 외형과 방향을 유지할 규칙
- 굵은 목조 기둥 네 개와 작은 밝은 돌 받침 네 개. 낮고 작은 사각 작업장입니다.
- 보라색 외쪽지붕 하나. 뒤쪽이 높고 앞쪽이 낮습니다. 주택처럼 가운데 용마루가 있는 지붕으로 바꾸지 않습니다.
- 앞면과 양 측면은 열고, 뒤쪽에만 낮은 가로 판자 벽을 둡니다.
- 정면에서 볼 때 작업대는 왼쪽, 통나무 더미는 오른쪽입니다.
- 작업대는 두꺼운 밝은 상판과 갈색 다리로 단순하게 만듭니다. 상판 재질은 밝은 목재로 통일하고 수동 톱 하나를 놓습니다.
- 통나무는 아래 두 개, 위 한 개로 쌓은 총 세 개입니다. 길이 방향은 건물 앞뒤, 밝은 단면은 정면을 향합니다.
- 통나무가 구르지 않도록 아래에 작은 나무 받침을 둡니다. 추가 창고나 큰 기계는 만들지 않습니다.
- 문·창문·굴뚝·성벽·탑 장식은 없습니다. 고블린 캐릭터도 이번 건물 시트에 포함하지 않았습니다.

## 시트를 읽는 방법
- 정면: 작업대가 화면 왼쪽, 통나무가 오른쪽입니다.
- 오른쪽: 건물의 앞쪽이 화면 왼쪽입니다. 따라서 지붕은 화면 오른쪽에서 왼쪽으로 낮아집니다. 가까운 통나무 옆면이 보이고 작업대는 뒤로 가려집니다.
- 후면: 낮은 뒷벽이 앞에 보이고, 그 너머 통나무는 화면 왼쪽, 작업대는 오른쪽입니다. 높은 뒤 처마와 그 아래 지붕 안쪽이 보입니다.
- 게임 시점: 정면과 오른쪽 측면을 함께 봅니다. 오른쪽에 별도 판자 벽을 추가하지 않습니다.

생성 시트는 참고 그림이므로 기둥 비율, 지붕 두께, 장식 수를 정확한 도면처럼 측정하지 않습니다. 실제 자산은 하나의 모델 또는 공통 기준으로 통일하고, 위 위치 규칙과 지붕 경사를 우선합니다.

## 배치와 구현 기준
- 첫 테스트의 논리 점유 면적은 2×2칸입니다. 돌 받침, 작업대, 통나무까지 영역 안에 넣습니다.
- 기준점은 점유 영역의 지면 중앙입니다. 그림의 점선은 배치 개념 표시입니다.
- 고블린이 서고 작업할 수 있는 높이와 공간을 실제 마을에서 확인합니다. 별도 시트끼리는 같은 축척이 아닙니다.
- 높은 게임 시점에서 지붕이 작업대와 통나무를 너무 가리면 처마 길이와 배치를 조정합니다. 생산 건물의 역할이 읽히는 것을 우선합니다.
- 주택·성·방어탑과 동일한 카메라, 그림자 방향, 재질 표현을 사용합니다.

## 첫 구현 역할
초기 목재 생산 건물로 연결합니다. 생산 시간, 생산량, 저장 한도, 건설 비용, 수령 방식은 아직 확정하지 않았으며 별도 게임 규칙으로 결정합니다. 그림에 보이는 통나무 세 개는 외형 요소이며 목재 보유량을 뜻하지 않습니다.

나무 베기, 톱질, 자원 수령 효과 같은 동작은 이번 이미지에 포함된 완성 애니메이션이 아닙니다. 먼저 건물 배치와 목재 생산 기능을 확인한 뒤 필요한 동작을 추가합니다.

## 제작 AI에 전달할 지시
이 자료로 기존 마을과 같은 스타일의 벌목소 한 채를 제작하세요. 뒤가 높고 앞이 낮은 지붕, 뒤쪽에만 있는 낮은 벽, 정면 기준 왼쪽 작업대와 오른쪽 통나무 세 개를 고정하세요.

- 3D를 선택하면 건물과 작업대·통나무를 공통 모델 기준으로 배치하고, 지면 중앙 기준점과 2×2칸 점유 영역을 설정합니다.
- 2D를 선택하면 실제 게임 시점으로 건물 한 채를 별도의 투명 이미지로 제작합니다. 참고 시트의 제목·테두리는 게임에 넣지 않습니다.
