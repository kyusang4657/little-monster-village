# 첫 플레이 버전 아트 가이드

## 1. 자료의 성격과 우선순위

이 묶음은 밝고 아기자기한 **마물 마을 건설·방어 게임**의 외형을 구현하기 위한 기준입니다. 플레이어 진영은 초록색 고블린과 보라색 건물, 인간 침입자는 은색 갑옷과 붉은 장비로 구분합니다. 큰 형태와 부드러운 모서리, 한눈에 읽히는 색 덩어리를 먼저 맞춥니다.

동봉한 이미지는 모두 생성형 AI로 만든 **불투명 배경의 참고 시트 또는 정적인 화면 시안**입니다. 실제 3D 모델, 리깅, 투명 스프라이트, 연속 애니메이션, 작동하는 게임과 UI는 포함하지 않습니다. 시트의 정면·측면·후면도 같은 모델을 정확히 투영한 도면은 아니므로, 서로 다른 그림의 사소한 차이를 별도 구조로 만들지 않습니다.

충돌하는 내용은 **이번 묶음의 주 제작 지시서·게임 규칙 → 이 가이드의 구조 기준 → 개별 자산 시트 → 전체 화면 → 과거 문서·생성 프롬프트** 순서로 적용합니다. 과거의 “개별 건물 하나만 시험” 지시는 당시 제작 단계의 기록입니다. 이번 첫 플레이 버전의 범위를 줄이는 조건이 아닙니다. 이미지 속 수치나 배치를 측정해서 게임 규칙을 새로 추정하지 않습니다.

## 2. 첫 구현에 사용할 표현 방식

이번 묶음에서는 **Godot 4 / GDScript / Compatibility 렌더러와 실시간 3D**를 임시 기본 경로로 제안합니다. 사용자가 앞서 확정한 엔진 선택은 아니며, 기존 프로젝트가 있다면 주 제작 지시서의 처리 방침을 따릅니다.

첫 구현은 상자·원기둥·구·단순 지붕 형태 등을 조합한 모델과 단색 재질로 만듭니다. 기본 도형을 코드로 조합해도 좋습니다. 성의 두 탑, 집의 지붕, 고블린의 큰 귀, 기사의 붉은 망토처럼 종류와 진영을 읽게 하는 요소부터 맞추고, 창틀·고글 테두리·문양은 후순위로 둡니다.

각 건물과 캐릭터는 독립된 장면으로 구성하고, **외형과 게임 기능을 분리**합니다. 나중에 전문 모델로 외형을 교체해도 배치 기준점, 점유 면적, 충돌, 저장 식별자, 무기 부착 위치가 유지되어야 합니다. 방어탑은 몸체·회전 석궁·조작 고블린·발사체를 나누어 실제로 조준할 수 있게 합니다.

전체 마을 이미지를 고정 배경으로 깔고 선택 상자만 움직이는 방식은 완성으로 인정하지 않습니다. 건물 이동, 캐릭터 이동, 가림, 회전, 발사체와 UI가 독립적으로 작동해야 합니다. 시트의 흰 여백·제목·패널 테두리를 게임 오브젝트에 붙이지 않습니다.

## 3. 카메라·축척·재질

| 항목 | 첫 구현 기준 |
| --- | --- |
| 화면 | 가로형. 16:9 구도를 출발점으로 하고 다른 휴대전화 비율에서도 주요 UI를 보존 |
| 투영 | 원근 왜곡이 없는 평행투영 카메라 |
| 카메라 방향 | 수평 회전 45°, 지면을 내려다보는 고도 50°를 초기값으로 설정 |
| 카메라 조작 | 한 손 배경 드래그로 이동, 두 손가락으로 확대·축소. 사용자 시점 회전은 제공하지 않음 |
| 격자 | 정사각형 한 칸의 한 변 = 월드 1단위 |
| 건물 기준점 | 점유 영역의 지면 중앙 |
| 캐릭터 기준점 | 두 발 사이의 지면 중심 |
| 초기 키 | 고블린 약 1.0단위, 기사 약 1.1단위. 머리 장식과 무기 돌출은 별도 확인 |
| 출입구 | 실제 통과할 문은 유효 높이 1.2단위 이상. 폭은 캐릭터 충돌체와 여유 공간을 확보 |
| 조명 | 장면 전체가 공유하는 부드러운 방향광과 충분한 주변 밝기 |

카메라 수치는 이미지에서 측정한 값이 아니라 이번 구현의 시작값입니다. 옛 주택 문서의 고도 약 55°보다 **이번 초기값 50°를 우선**합니다. 실제 휴대전화 화면에서 조정할 수 있도록 설정값으로 두되, 플레이 중에는 방향을 고정합니다.

캐릭터와 건물 시트는 서로 같은 축척이 아닙니다. 이미지의 픽셀 높이를 그대로 월드 크기로 환산하지 않습니다. 고블린이 주택 문과 탑 발판에 자연스럽게 맞고, 기사가 정문과 성 앞 통로를 통과하는지 같은 장면에서 확인합니다. 발은 지면에 붙이고 그림자는 한 방향으로 통일합니다.

주택·방어탑·벌목소의 점유 면적은 **2×2칸**, 성은 **3×3칸**입니다. 계단·사다리·통나무까지 해당 범위 안에 수용합니다. 지붕과 장식도 이웃 건물을 심하게 가리지 않게 조절합니다. 점유 영역의 크기와 배치 판정은 게임 데이터가 결정하며 그림 속 점선이 결정하지 않습니다.

색은 밝은 잔디, 아이보리 돌과 벽, 꿀빛 목재, 보라색 지붕과 깃발을 중심으로 씁니다. 성문은 청록색입니다. 광택이 강한 금속, 촘촘한 실사 질감, 과도한 발광과 어두운 그림자는 줄입니다. 낮은 확대 배율에서도 주택·성·벌목소·방어탑의 실루엣이 구별되어야 합니다.

성의 옆면에는 창 하나씩, 후면에는 창 두 개를 둡니다. 성문은 정면에만 있습니다. 지붕 뒤 중앙의 작은 깃대는 중앙 탑으로 해석하지 않습니다. 초기 분위기 이미지에 등장하는 더 복잡한 성과 혼합하지 않습니다.

주택의 오른쪽 면에는 창 두 개, 후면에는 창 하나를 둡니다. 후면에는 문·계단·둥근 다락창이 없습니다. 굴뚝은 정면에서 오른쪽, 후면에서 왼쪽에 보여야 합니다. 미제공 왼쪽 면은 단순한 벽면부터 시작합니다.

벌목소 통나무는 아래 둘·위 하나로 쌓고 길이 방향은 건물 앞뒤로 둡니다. 밝은 단면은 정면을 향합니다. 통나무 세 개는 장식 구조이며 보유 목재 3개라는 뜻이 아닙니다. 오른쪽 측면에 별도 벽을 추가하지 않습니다.

방어탑 몸체는 고정하고 석궁과 조작자를 함께 목표 방향으로 돌립니다. 활대와 발사체가 난간에 닿지 않는 높이와 회전 여유를 확보합니다. 조작자는 일꾼과 같은 외형을 사용하되 망치를 들지 않습니다. 사다리와 난간 개구부가 실제로 연결되어야 합니다.

울타리는 칸 전체를 차지하는 건물과 달리 **격자 변에 배치**합니다. 기둥은 꼭짓점에서 공유해 중복시키지 않습니다. 폭 2의 출입문을 만들 때 그 구간의 가로목과 가운데 기둥을 제거합니다. 옛 연결 시험의 올바른 치수는 6×3이며, 과거 생성 프롬프트의 5×3은 적용하지 않습니다. 이 시험 사각형은 전체 마을 크기가 아닙니다.

## 5. 세 화면의 사용법과 UI

| 화면 | 구현에서 참고할 내용 |

| `references/screens/village.png` | 성 1채·주택 2채·벌목소 1채·방어탑 2개의 여섯 건물, 한 겹 울타리, 열린 중앙 정문, 여유 있는 통로와 오른쪽 확장 공간. 벌목소는 최종 화면의 왼쪽 뒤 위치를 참고 |

전체 화면은 분위기와 기능 배치의 참고입니다. 건물의 정확한 창·굴뚝·사다리·무기 구조는 개별 기준을 따릅니다. 지형, 건물, 인물, 그림자, 선택 표시, 체력 막대, 패널과 글자를 독립된 요소로 제작합니다.

건설 화면은 새 주택 구매 화면이 아닙니다. 구매·자원 수령·결과 화면 등 아직 그림이 없는 기능은 주 제작 지시서에 따라 같은 UI 재질로 만듭니다. 초록색만으로 배치 가능 여부를 알리지 말고 아이콘과 문구를 함께 사용합니다. 배치 불가 상태에는 이유와 비활성화된 확정 버튼이 필요합니다.

UI는 밝은 아이보리 패널과 짙은 보라색 글자를 기본으로 하고, 중요한 확정 동작은 초록색으로 강조합니다. **한국어 문구는 실제 UI 텍스트**로 표시하며 이미지에 구워 넣지 않습니다. 작은 휴대전화에서도 읽고 누를 수 있는 크기로 조정하고 화면 안전 영역을 확보합니다. UI 터치가 뒤의 마을 선택으로 전달되지 않게 합니다.

## 6. 동작과 시각 검수

고블린과 기사 시트의 대기·이동·공격은 동작별 대표 자세입니다. 공격 그림은 무기를 들어 올린 준비 자세이므로 실제로 필요한 준비·타격·복귀를 별도로 만듭니다. 첫 버전에서는 단순한 관절 회전과 걷기 동작부터 구현해도 됩니다. 공격 피해가 발생하는 시점은 실제 타격 또는 발사 규칙과 맞춰야 합니다.

지상 일꾼의 망치 자세가 있다는 이유로 근접 전투를 추가하지 않습니다. 옛 일꾼 문서의 전투 역할보다 이번 주 제작 지시서의 범위를 우선합니다. 방향을 바꾸어도 캐릭터의 장비 손은 유지하고, 모델이나 이미지를 좌우 반전하여 검과 방패를 바꾸지 않습니다.

검수는 같은 장면에서 진행합니다.

- 축소한 가로 화면에서도 여섯 건물의 종류와 빈 건설 공간을 구분할 수 있다.
- 주택을 90°씩 돌려도 문·창·굴뚝이 함께 회전하고, 점유 표시와 실제 바닥 위치가 맞는다.
- 고블린과 기사의 발이 지면에 닿고 건물 앞뒤 가림이 자연스럽다.
- 울타리 접합부에 중복 기둥이 없으며 정문 통로와 주요 이동로가 열려 있다.
- 방어탑의 석궁·조작자·발사 방향이 일치하고 난간을 뚫고 발사하지 않는다.
- 마을을 이동하거나 확대해도 버튼과 한국어 문구가 읽히며, 선택한 건물을 패널이 가리지 않는다.

첫 플레이 버전의 완료는 참고 그림과 픽셀 단위로 같아지는 것이 아니라, 위 특징을 유지한 독립된 오브젝트로 건설과 방어가 실제로 작동하는 것입니다. 세부 모델과 장식은 이 기준을 유지하며 이후 교체합니다.
