# 4차 설계 결정: 만화풍 화풍 · 주인공 뿔이 · 유닛 직접 생산 (v0.4.0)

수치는 `config/prototype-defaults.json`(유닛은 `units`, 건물은 `barracks`·`training_ground`)이 기준입니다.

## 1. 화풍

- 다른 게임의 그림·캐릭터·로고·글꼴은 쓰지 않고 화풍 규칙(외곽선, 두툼한 비율, 젤리 버튼, 양피지 창)만 정해 직접 만든 모델·UI에 적용했습니다. 규칙 표: `docs/design/style/README.md`.
- 글꼴: 주아체·검은고딕(둘 다 OFL, Google Fonts 저장소). 나눔고딕은 더 쓰지 않아 뺐습니다(APK 크기 절약).
- 외곽선 비용: 최대 부하에서 삼각형이 약 2.5배가 됩니다(데스크톱 소프트웨어 렌더러 측정). 그래서 배경 나무는 외곽선을 빼고, 메뉴에서 외곽선을 끌 수 있게 했습니다. FPS 가 계속 낮으면 게임이 그림자·외곽선 끄기를 한 번 안내합니다.

## 2. 뿔이(주인공)

- 디자인: `docs/design/imp/README.md`. 2.3등신, 짝짝이 뿔(왼쪽은 끝까지 작음), 물려받은 망토(Lv.1 은 바닥에 끌림), 사탕 지팡이, 연두 눈.
- 마을 상주는 외형·연출 전용입니다(규칙에 영향 없음). 대사는 `config/story.json`(`imp_taps`, `imp_levelup`)에 고정.

## 3. 유닛 직접 생산

| 항목 | 값 | 이유 |
| --- | --- | --- |
| 해골 막사 | 2×2, 목재 100, 20초, 1개, 성 Lv.1 | 처음부터 유닛을 써 볼 수 있게 |
| 오크 훈련장 | 2×2, 목재 120, 20초, 1개, 성 Lv.2 | 1장을 끝낸 보상 |
| 인구 | 완성된 주택 1채당 1명(최대 10) | 주택에 쓸모를 주고, 유닛 수 상한 |
| 훈련 | 궁수 목재 25·12초, 오크 35·15초, 건물마다 대기 5 | 목재는 대기열에 넣을 때 한 번. 마을 시간에만 진행(전투·일시정지 중 멈춤) |
| 해골 궁수 | 피해 4, 사거리 2.3칸, 1.3초 | 깃발 뒤에서 쏘는 움직이는 작은 방어탑 |
| 꼬마 오크 | 체력 110, 피해 6, 1초, 0.6칸 안 기사 2명까지 막음 | 길 위에서 기사를 붙잡아 탑이 쏠 시간을 번다 |
| 집결 깃발 | 마을 안 빈칸, 무료로 옮김. 정하지 않았거나 자리에 건물이 들어서면 성 앞 | 가벼운 지휘(유닛을 하나하나 움직이지 않음) |
| 쓰러짐 | 전투가 끝나면 모두 돌아옴 | 영구 손실 없음 원칙 |

### 정한 것과 이유

- **가벼운 지휘:** 휴대폰에서 유닛을 하나씩 지휘하면 손이 바빠지고 화면이 가려집니다. 깃발 한 개로 "어디서 막을지"만 정하게 했습니다.
- **방어탑 중심 유지:** 처음 수치(궁수 피해 7, 오크 체력 160, 주택당 2명)로는 유닛 20명만으로 10단계를 성 피해 없이 이겨 방어탑이 필요 없어졌습니다. 그래서 수치를 낮추고 인구를 주택당 1명으로 줄였습니다. 지금은 유닛 10명 + 처음 방어탑 2개로 10단계를 지고(자동 검사), 2·3단계는 유닛 4명이면 이깁니다.
- **기사는 유닛을 노리지 않습니다:** 오크에게 막힌 기사만 그 오크와 싸웁니다. 기존 "기사는 성(과 앞마당)을 노린다" 규칙과 길 검사를 그대로 둡니다.
- **자원은 목재 하나:** 두 번째 자원은 화면과 균형을 복잡하게 해서 이번에는 넣지 않았습니다.
- **직접 건설:** 건설은 지금도 플레이어가 자리를 정하고 일꾼이 가서 짓습니다. 일꾼을 직접 고르는 조작은 휴대폰에서 번거로워 넣지 않았고, 대신 일꾼이 넓힌 땅까지 걸어가게 고쳤습니다(3차 검토 반영).

## 4. 저장 형식 v4

`units`, `rally`, 건물별 `train_queue`·`train_left` 추가. v1~v3은 자동 이전(유닛 0, 깃발 기본). 인구 한도 초과·모르는 유닛·경계 밖 깃발·대기열 범위 밖 값은 거부합니다.
