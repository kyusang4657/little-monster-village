# 캐릭터 컨셉 시트(5차 기준 그림)

사용자가 준 컨셉 그림 2장입니다. 5차 캐릭터 리디자인은 **게임 모델을 이 그림에 최대한 맞추는 것**이 목표입니다. 그림의 분위기(둥글고 매끈한 장난감 질감, 2.5~3등신, 또렷한 눈)를 따르되, 모델은 외부 파일 없이 `CharGeo` 도형으로 만듭니다.

| 파일 | 내용 |
| --- | --- |
| `sheet-1-cast.jpg` | 출연진 전체: 뿔이(Lv.1~4·표정·3D 도안·부품), 고블린 3종, 해골 궁수, 꼬마 오크, 후보 몬스터(슬라임·박쥐·버섯), 기사 5종, 기사단장 번쩍경, 용사 루루, 후보 인간 유닛, 비율 가이드 |
| `sheet-2-imp.jpg` | 뿔이(하이브리드 마왕) 상세: 큰 그림, 턴어라운드, 표정 3종, 성장 Lv.1~4, 디테일(세로 동공·비늘·왕관·망토), 크기 비교 |
| `crops/` | 위 두 장을 캐릭터별로 잘라 2배로 키운 그림(에이전트 참고용) |

## 비율(시트의 공통 비율 가이드)

거대형 3.5등신(보스), 일반형 3등신(기사·고블린·오크), 소형 2.5등신(뿔이·해골). 키(HEIGHT)는 검사 기준을 유지합니다: 고블린 1.0, 기사 1.15, 보스 1.3.
