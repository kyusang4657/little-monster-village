# 만화풍(두툼한 모바일 전략 게임 느낌) 화풍 규칙

다른 게임의 그림·캐릭터·로고·글꼴은 쓰지 않고, 화풍 규칙만 정해 직접 만든 모델·UI에 적용합니다.

| 영역 | 규칙 | 구현 |
| --- | --- | --- |
| 외곽선 | 캐릭터·건물·울타리에 짙은 갈색 외곽선. 얼굴 부품·바닥·꽃·배경 나무는 제외. 작은 부품은 가늘게 | 뒤집은 껍데기(법선 방향으로 부풀린 뒷면). 캐릭터는 정점 알파, 건물은 부품별 평균 법선(CUSTOM0)과 부품 크기 배율 |
| 명암 | 윗면 밝게, 아랫면 어둡게 | 정점 색에 미리 칠함(`CharacterRig.Geo._vert`, `MeshBatch._add`) |
| 비율 | 큰 주먹·장화, 넓은 어깨, 큰 방패·검 | 기사·보스·고블린·뿔이 사양 값(`hand_s`, `boot_s` 등) |
| 표정 | 걷는 기사는 벼른 얼굴(`fierce`), 공격은 화남 | `CharacterRig.EXPR` |
| 색 | 조금 더 진하게(채도 ×1.08, 대비 ×1.06), 풀색은 깊은 초록 | `WorldView._setup_environment` |
| UI | 젤리 버튼(외곽선·광택·눌림 두께), 양피지 창, 어두운 자원 막대, 흰 제목 + 두꺼운 외곽선, 아이콘 외곽선 | `scripts/ui/ui_skin.gd`(코드로 그린 질감), `hud.gd`, `ui_icon.gd` |
| 글꼴 | 본문 주아체, 큰 제목·숫자 검은고딕(둘 다 OFL) | `assets/fonts/` |

성능(데스크톱 소프트웨어 렌더러, 실기기 아님): 최대 부하에서 외곽선 켬 그리기 호출 453·삼각형 51.3만, 그림자·외곽선 끔 261·20.7만. 메뉴에서 외곽선을 끌 수 있고, FPS 가 계속 낮으면 게임이 한 번 안내합니다.
