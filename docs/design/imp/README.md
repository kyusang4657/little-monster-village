# 뿔이(어린 마왕) 디자인 시안

주인공 뿔이의 게임 모델 시안입니다. 성격은 "무서워지고 싶은데 귀여운" 어린 마왕입니다. 모델은 이미지가 아니라 실제 게임 리그(`CharacterRig.imp(level)`)로 만들었고, 아직 게임 화면에는 넣지 않았습니다.

| 항목 | 정한 것 |
| --- | --- |
| 비율 | 키 약 0.86(뿔·지팡이 제외, 머리카락 포함), 약 2.3등신. 고블린(1.0)보다 작고 머리가 큼 |
| 실루엣 | 짝짝이 뿔(오른쪽이 큼), 물려받은 큰 망토, 사탕 보석 지팡이, 정수리 말린 머리카락 한 가닥, 스페이드 꼬리 |
| 색 | 라벤더 피부, 보라 옷·망토(마을 지붕과 같은 계열), 눈과 왕관 보석만 연두색 |
| 얼굴 | 머리 가운데보다 낮은 큰 눈, 연한 눈썹, 오른쪽 송곳니 하나, 분홍 볼. 표정 5가지(보통·기쁨·화남·아픔·눈 감음) |
| 성장(성 레벨) | Lv.1 작은 뿔·바닥에 끌리는 망토와 큰 깃 → Lv.2 뿔이 자라고 망토 끝을 묶음 → Lv.3 금 어깨 장식·금 단·빛나는 보석 → Lv.4 왕관·가슴 문장·몸에 맞는 망토. 왼뿔은 Lv.4에서도 작게 남김(정체성) |
| 동작 | 대기(숨쉬기), 걷기(지팡이 팔은 고정, 빈 팔만 흔듦), 무서운 척 → 휘청(`pose_scare`), 환호 점프(`pose_cheer`) |
| 예산 | 삼각형 2,657~3,044(보스 예산 4,500 이하), 메시 1개 |

그림: `1-levels-views.jpg`(레벨×정면·3/4·옆·뒤), `2-lineup.jpg`(고블린·뿔이 Lv.1~4·기사 키 비교), `3-motions.jpg`(대기·걷기·무서운 척·환호), `4-faces.jpg`(표정).

다시 만들기: `xvfb-run -a godot --path . --rendering-driver opengl3 --resolution 420x480 --script res://tests/character_capture.gd -- --out=<폴더> --mode=imp`

## 마을 상주(3단계)

- 뿔이는 마을을 산책합니다(성 앞 → 주택 앞 → 벌목소 앞, 건물·울타리를 피해 걷기). 목적지 세 번에 한 번 "무서운 척 → 휘청"을 합니다.
- 누르면 깡충 환호하며 한마디 합니다(`config/story.json`의 `imp_taps`, 누를 때마다 다음 대사).
- 전투 중에는 성 뒤에서 걱정스러운 얼굴로 지켜봅니다.
- 성이 자라면 결과·이야기 장면이 끝난 뒤 성에서 빛기둥과 반짝이가 솟고 "Lv.N!"이 뜨며, 뿔이가 그 레벨의 모델로 바뀌어 환호하고 축하 대사(`imp_levelup`)를 합니다.
- 이야기 대화창 얼굴 그림도 새 디자인(짝짝이 뿔, 연두 눈, 말린 머리카락, 송곳니)으로 바꿨습니다.
- 그림: `5-in-village.jpg`
